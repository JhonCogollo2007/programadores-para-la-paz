Al enviar una petición POST a http://localhost:3000/registro con el siguiente JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

El servidor responde con:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Explicación:
El servidor recibe los datos gracias al middleware express.json(), que interpreta
el cuerpo de la petición en formato JSON. Luego, mediante req.body, se accede a
los campos "nombre" y "mensaje" que el cliente envió. Finalmente, el servidor
responde con un objeto JSON que confirma la recepción de los datos junto con
los valores recibidos.
