Al enviar una petición POST a http://localhost:3000/reportes con el siguiente JSON:

{
  "tipo": "Infraestructura",
  "descripcion": "Daño en alumbrado público"
}

El servidor responde confirmando que el reporte fue registrado:

{
  "mensaje": "Reporte registrado",
  "reporte": {
    "id": 1,
    "tipo": "Infraestructura",
    "descripcion": "Daño en alumbrado público"
  }
}

Luego, al consultar la ruta GET http://localhost:3000/reportes, el servidor devuelve
la lista completa de reportes almacenados en memoria:

[
  {
    "id": 1,
    "tipo": "Infraestructura",
    "descripcion": "Daño en alumbrado público"
  }
]

Si se envía un segundo reporte por POST, al consultar nuevamente con GET aparecen
los dos reportes en la lista. Los datos se almacenan en el array llamado "reportes"
mientras el servidor permanece encendido. Si se reinicia el servidor, la lista
vuelve a estar vacía porque aún no se usa una base de datos.
